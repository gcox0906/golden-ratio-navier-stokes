  cd golden-check
  git checkout -b golden-auxiliary-covering f9e8bc5b38b6e212696e8a30e3e91517af887bbd
  git apply /absolute/path/to/golden-covering.patch

For the complete library and audits, the supplied script copies exactly the
verified changes (including both audit modules), obtains the pinned cache,
builds NavierStokes with warnings as errors, and records new logs:
  bash /absolute/path/to/verify_golden_integration.sh /absolute/path/to/golden-check

For the independent checker, install the pinned checker dependencies then run:
  lake exe comparator ComparatorChallenges/NavierStokes.json

The original NavierStokes JSON has enable_nanoda=true. Do not change the
challenge definitions or configuration. Exact successful logs and their
manifest are in checker-logs. checker-reproduction contains the Ubuntu 24.04
setup, environment, source payload, sandbox wrapper and collector used for
the recorded independent verification. Consult comparator-status.txt for
the container seccomp substitution and its limited sandbox assurance.
